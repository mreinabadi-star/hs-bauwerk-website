# H&S Bauwerk GmbH website

German and Persian static website. German home: index.html; Persian home: fa/index.html.

## GitHub Pages
Publish from main, repository root. No build is required. .nojekyll disables Jekyll.

The contact form prepares an email in the visitor’s email application; it does not send mail from a server.

Set canonical URLs and sitemap with prepare_release.py after the Pages address is confirmed.
